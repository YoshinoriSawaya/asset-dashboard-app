# E07-07: 生活防衛資金の回復プラン提示
親: [E07: 目標(Goal)管理機能](../epics/E07-goal-management.md)

## 概要
生活防衛資金(E07-06)が目標額を下回った場合、不足額を算出し、
「月々いくら追加すればNヶ月で回復するか」を自動計算して提示する。
下回った状態はE05経由でリマインダー通知もする。

## 計算方法
不足額 = 目標額 - 現在の残高
回復プランは複数パターンを提示する(例: 3ヶ月で回復/6ヶ月で回復
それぞれの月額積立額)。デフォルトの回復期間は設定可能にする。

## 完了条件
生活防衛資金が基準を下回ると通知が届き、詳細画面に「月々◯円で
Nヶ月後に回復」という具体的な提案が表示される。

## 作ったもの(計算と表示)
`RecoveryPlan`(純粋関数)。目標に届いていないとき、目標の詳細画面に出す:

```
不足分を埋めるには
3か月で: 月々 ◯円
6か月で: 月々 ◯円
12か月で: 月々 ◯円
```

AI用の書き出し(E03-07)の目標の行にも同じ提案を付けた。

## 設計の決定

### 生活防衛資金に限らず、Goal全般に出す
計算は「目標 − 現在」を月数で割るだけで、取り崩した生活防衛資金を戻すときも、
車の頭金を貯めるときも同じ。目標の種類(維持する/貯める)を分けるのは
E07-11(期日とランプアップ)の仕事なので、ここでは分けず「不足分を埋めるには」
という言い方にした。期日から逆算した積み立て額はE07-11で出す。

### 期間は3・6・12か月の3つ
概要の「複数パターン」。3か月・半年・1年の目安で、どれを選ぶかは本人。
「既定の回復期間を設定できる」は、目標ごとの設定を足す必要があるので
まだ入れていない(下記)。

### 月額は千円単位で切り上げる
切り捨てるとN か月積んでもわずかに届かない。切り上げなら必ず届き、
数字も読みやすい。テストで「月額 × 月数 ≥ 不足額」を確かめている。

## 検証 (2026-09-26)
**JVMユニットテスト(170件、うち追加5件)**: `RecoveryPlanTest`
- 千円単位の切り上げ、割り切れるとき、届いているとき、分からないとき
- 詳細とAI用の書き出しに出ること

**エミュレータで実データ**: 目標額を大きくした確認用の目標(系列は `預金・現金`)を
ローカルDBに一時的に入れ(Driveには書かない)、詳細画面の3・6・12か月の月額が、
DBの最新値から別に計算した値と一致し、月額×月数が不足額以上になることを確かめた
(金額は出力していない)。確認後に消した。

## 未実装のまま残したこと
- 既定の回復期間を目標ごとに設定すること(今は3・6・12か月を全部出す)
- 「一定額を保っておく」目標と「貯めて届かせる」目標の区別(E07-11で種別を持たせる)

## 通知(E05で追加)
端末の毎日の確認(E05)で通知するようにした。生活費から出す目標を下回っていれば30日に1度。文面に金額は出さない。ユニットテストで確認した(エミュレータでは、その状態を作っての通知までは見ていない)。
