# E03-11: トップの入口を整理する
親: [E03: ダッシュボードUI・詳細画面](../epics/E03-dashboard-ui.md)

## 概要
2026-09-26〜27に機能を足すたびに、トップの項目一覧の下へ入口(文字のボタン)を1行ずつ足してきた結果、13個が縦に並び、
目当ての入口を探しにくくなった。まとまりごとに分けて並べ直す。本人が「次の作業」の候補から選んだ(2026-09-27)。

## 完了条件
トップの入口が、見出しのついたまとまりごとに2列のボタンで並ぶ。どのボタンも今までと同じ画面を開く。

## 作ったもの
`TopScreen` の入口を `MenuGroup`(見出し + 2列のボタン)で4つのまとまりに分けた:

| まとまり | ボタン |
|---------|--------|
| 振り返る | 前の月の振り返り / カテゴリ別の支出 / 固定費・サブスク |
| 貯める・備える | 積立投資の目安 / 余剰資金の配分 / 大型出費の予定 |
| 追加する | + 目標 / + リマインダー / + 手入力の系列 |
| 設定・取り込み | 明細のカテゴリ / 予定の取り込み / AI相談用にコピー / ウィジェットを置く(置いていなければ) |

## 設計の決定
- **見出し + 2列のボタン**(本人が選んだ)。見出しをつけて縦に並べ替える案は選ばなかった。縦の長さがほぼ半分になる
- **ボタンの名前は短く**: 括弧書きの説明(「(ボーナスなど)」など)は外した。詳しくは開いた先の画面に書いてある
- **まとまりは「何をしたいか」で分けた**: 振り返る(使ったお金を見る)/貯める・備える(これからのお金)/追加する/設定・取り込み
- 同期・月次サマリー・純資産・リマインダーの一覧・アプリのロックは、今までの場所のまま(よく使うものは上にある)
- 奇数のまとまりは最後の段を左だけにし、ボタンの幅をそろえる
