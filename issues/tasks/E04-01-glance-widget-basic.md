# E04-01: Glanceウィジェットの基本実装
親: [E04: Androidウィジェット](../epics/E04-widget.md)

## 概要
Jetpack Glanceを使い、ホーム画面に配置できる最小限のウィジェットを
実装する。

## 完了条件
ホーム画面にウィジェットを追加できる。

## 作ったもの
`widget/SyncStatusWidget.kt`(Glance)と、`res/xml/sync_status_widget_info.xml`。
1×1マスで、大きさは変えられる。色と短い言葉だけを出す(E04-02)。

置き方は2つ:
- ランチャーのウィジェット一覧から「資産ダッシュボード」
- **アプリのトップの「ホーム画面にウィジェットを置く」**。Androidの
  `requestPinAppWidget` で、ランチャーの「ホーム画面に追加」確認が出る。
  置いてあれば、次に開いたときからこのボタンは出ない

## 設計の決定

### アプリから置けるようにした
ウィジェット一覧の検索は英字で探すが、アプリ名が日本語なので `asset` では
見つからない(エミュレータで確認)。一覧をスクロールして探す手間を省くため、
アプリから置く入口を付けた。

### 数字は出さない
CLAUDE.mdの「ウィジェットは通知専用」。人前でホーム画面を開いても金額が
見えない。テストで、表示する文字と読み上げの説明に数字が入らないことを確かめている。

## 検証 (2026-09-25)
エミュレータ(Pixel 9 / API 37)で、アプリの「ホーム画面にウィジェットを置く」
→ ランチャーの確認画面「Add to home screen」→ ホーム画面に置かれた。
読み上げの説明(`資産ダッシュボード: 同期は不要です。タップして開く`)も出ている。

## 未検証のまま残したこと
- 実機のランチャー(Pixel以外)
- 置いた直後は、アプリに戻ってもボタンが残る(画面を描き直したときに
  判定しているため)。次に開いたときには消える
