# E05-06: 保険・税金の更新リマインダー
親: [E05: 通知基盤](../epics/E05-notifications.md)

## 概要
車の任意保険更新日、確定申告・年末調整の時期など、見落としやすい
年次イベントをReminderとして登録し、事前に通知する。

## 完了条件
更新日・申告時期が近づくと通知が届く。

## 作ったもの(E05全体)
通知は**すべて端末の中で出す**。サーバーもFCMも使わない(本人が決めた)。

| 部品 | 役割 |
|------|------|
| `notify/NotificationRules` | 今日、何を通知するか(純粋関数) |
| `notify/DailyCheck` | 1日1回(朝9時ごろ)アラームで起き、ルールを当てて通知し、次を予約する |
| `notify/NotifyStore` | 通知ごとに最後に出した日(端末の中だけ) |
| `RescheduleReceiver` | 再起動・アプリの更新で消えたアラームを予約し直す |
| トップのバナー | Android 13以降の通知の許可を求める |

詳しい設計の判断は [E05の親エピック](../epics/E05-notifications.md)。

## このタスクの中身
リマインダー(E02-01の汎用スキーマのReminder)を**画面から登録**できるようにし
(トップの「+ リマインダーを追加」)、期日の**7日前と当日**に通知する。
それぞれ期日ごとに1度だけ。

- 詳細画面の「済みにする」: 繰り返すもの(毎年・毎月)は次の期日へ進め、
  繰り返さないものは消す。期日を過ぎてから済みにしても、次の期日は
  「元の期日 + 1年/1か月」(車検・保険の更新日のように期日が決まっているため)
- 保存先はDriveの `settings/items.json`(目標と同じ)

## 検証 (2026-09-26)
- ユニットテスト: 7日前と当日、それぞれ1度だけ、8日前と過ぎた後は出ない。
  済みにしたときの次の期日(大きく過ぎていても今日より後まで進める)
- エミュレータ(Driveに実際に書いた): 3日後が期日のリマインダーを追加 →
  確認で「あと3日: ◯◯」が出た → 済みにすると期日が1年後へ → 削除

保険の更新日・確定申告・年末調整も、毎年のリマインダーとして登録する。
