# E07-22: カテゴリの決まりのまとめ取り込み
親: [E07: 目標(Goal)管理機能](../epics/E07-goal-management.md)

## 概要
明細のカテゴリ(E07-21)で、前の除く言葉を引き継いだ「生活費以外(引き継ぎ)」に527件(摘要132種類)が残り、
スマホで1件ずつ付け直すのは大変だった。本人から「例を出すか、自動で設定してみてほしい」(2026-09-26)。
分け方の案を出し、本人が選んだ形で、CSVからまとめて取り込めるようにした。

## 完了条件
「言葉,カテゴリ,種類」のCSVをDriveに置くと、アプリで中身を確かめてからカテゴリの決まりに取り込める。

## 作ったもの
- `ui/CategoryImport.kt`(純粋関数): Driveの `settings/category_rules.csv` を読み、今のカテゴリと突き合わせる
  - 種類は 生活費・遊び代・大型出費・振替・積立投資。無いカテゴリはその種類で作る
  - カテゴリが空の行は、その言葉に当たる決まりを外す(カテゴリなし=生活費に戻す)
  - **取り込む言葉を含む細かい決まりは外して寄せる**(下)
- `ui/CategoryImportScreen.kt`: 明細のカテゴリの画面の「CSVからまとめて取り込む」から開く。足す・外す決まり、
  新しいカテゴリ、読めない行を見せてから取り込む。取り込めたら、下のカテゴリの画面も閉じる

## 設計の決定
- **CSVで取り込む**(本人が選んだ)。エミュレータの画面を私が操作して付ける案は、操作が多く壊れやすいので捨てた。
  取り込み口は残るので、明細が増えたときにも使える
- **取り込む言葉を含む細かい決まりは外す**: カテゴリは長い言葉が勝つ(E07-21)。引き継いだ決まりは摘要まるごとの
  長い言葉なので、短い言葉で付けても変わらない。外すものは取り込む前に見せる
- **同じ名前のカテゴリが別の種類であれば、今の種類のまま**: 本人が付けた種類を上書きしない。画面で知らせる
- **取り込めたら、カテゴリの画面も閉じる**: 取り込む前の内容を持ったまま、そこで保存すると上書きしてしまうため

## 本人のデータ向けに作ったCSV(リポジトリの外)
`E:\Engineering\_secrets\category_rules.csv`(約100行)。引き継いだ摘要132種類を見て、本人が選んだ案で分けた。
- 家電量販店・家具店 → 家具・家電(大型出費)、カー用品店 → 車のメンテ(大型出費。「車のメンテ」の積立で準備するため)
- スーパー・コンビニ・自販機 → 食費、飲食店 → 外食(遊び代)、交通系・ETC・駐車場・ガソリン → 交通、
  ドラッグストア・ホームセンター・衣料 → 日用品、携帯・家賃・手数料 → 通信・住まい(いずれも生活費)

摘要ごとの長い言葉が勝つ落とし穴を避けるため、言葉を選んだ(例: ドラッグストアの摘要がショッピングモールの

意図した4種類だけであることを確かめた(額は見ていない)。

**エミュレータで、本人がDriveに置いたCSVで確認した**(取り込むは押していない):

### 取り込んだあとの積立投資の目安(E10-04)
「収入から引くと残りがありません」と出た。内訳を収入に対する割合で見ると(額は出していない)、消費71%・
**生活防衛資金の足りない分を6か月で埋める月額46%**・大型出費の積立6%で、今の積立は25%。目安を0にしているのは
生活防衛資金の不足。生活防衛資金・家まわり・車・家電は同じ預金・現金を一覧の上から分け合う(E07-10)が、並びが
名前順で「家まわり」が生活防衛資金より上にあり、不足が大きく見えている可能性がある。並べ替えは本人に伝えた
