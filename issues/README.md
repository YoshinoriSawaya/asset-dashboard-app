# 資産ダッシュボードアプリ - Issue一覧

エピック(親イシュー)は `epics/`、タスク(子イシュー)は `tasks/` に
フラットに置く。ファイル名のプレフィックス(E00, E01...)でエピックに
紐づく。

## エピック一覧(着手順の目安)

| ID | エピック | 状態 | 依存 |
|----|---------|------|------|
| E00 | 開発環境構築 | ほぼ完了 | なし |
| E01 | Google Drive連携基盤 | 進行中 | E00 |
| E02 | ローカルデータモデル・キャッシュ基盤 | 未着手 | E01 |
| E03 | ダッシュボードUI・詳細画面 | 未着手 | E02 |
| E04 | Androidウィジェット | 未着手 | E02 |
| E05 | 通知基盤 | 未着手 | E02 |
| E06 | セキュリティ・バックアップ復元 | 未着手 | E01, E02 |
| E07 | 目標(Goal)管理機能 | 未着手 | E02, E03 |
| E08 | リリース・配布 | 未着手 | E02〜E07 |

E03・E04・E05は互いに並行して着手できる(いずれもE02完了が前提)。

E00は E00-04(実機のUSBデバッグ有効化)と E00-06(署名キーストア作成)
だけが残っている。どちらも本人の手作業が必要だが、E01の実装は
エミュレータで進められるのでブロックにはならない。

## 運用ルール
- 各タスクのステータスは「未着手/進行中/完了」の3段階
- タスクを完了したら、対応する親エピックのチェックボックスも更新する
- 新しいアイデアはこのissues構造に落とし込む前に、まずローカルの
  メモとして書き留めておき、形になったらタスク化する
