# E09-05: 将来の評価額の積立額を、系列ごとの積立投資のカテゴリにする
親: [E09: 将来予測機能](../epics/E09-forecasting.md)

## 概要
将来の評価額(E09-03)の積立額は、明細の種類が「積立投資」の全部の月平均だった。E07-23で年金の掛金を
積立投資にしたため、NISA(投資信託)の評価額に年金の掛金まで足されるようになった。
系列ごとに、積立額にする積立投資のカテゴリを選べるようにする。

## 完了条件
投資信託の将来の評価額が、NISAの積立だけで計算される。年金の掛金は入らない。

## 作ったもの
- Metricの「名前・表示を変更」に**「積立額にするカテゴリ」**(全部 / 種類が積立投資のカテゴリ)。想定利回りを入れたときだけ出す
- 選んだカテゴリの月平均を積立額にする(`Summary.categorySpending` と `InvestPlan.currentMonthlyYen` の `amount`)。
  詳細には「積立は明細のカテゴリ「◯◯」の月平均」と、どこから取ったかを出す
- `Item.Metric.investCategory`。DBでは既存の `fundId` 列(Reminderでは積立先の目標)に入れ、
  `items.json` では `investCategory` という別の名前で書く

## データの分け方(2026-09-27、エミュレータから本人のDriveの categories.json に保存した)
- 「年金の掛金」(種類は積立投資)を新しく作り、年金の掛金の摘要をそちらへ移した
- 「積立投資」にはNISAのクレカ積立だけが残った(明細 9件 / 年金の掛金 28件)

投資信託の系列の利回りと積立額のカテゴリは、**本人がまだ決めていないのでDriveには保存していない**。
スマホで投資信託の「名前・表示を変更」から、利回りと「積立投資」を選んで保存する。

## 設計の決定
- **カテゴリ名で選ぶ**: 積立投資の種類の中を系列ごとに分ける手段は、今はカテゴリしか無い。
  摘要の言葉を系列ごとに持つ案は、カテゴリ(E07-21)と同じことを二重に持つので捨てた
- **月の選び方は積立投資の目安と同じまま**: そのカテゴリの明細が無い月も0として平均に入れる。
  カテゴリの明細がある月だけで平均すると、始めたばかりの積立が多めに出る
- **選ばなければ今までどおり全部**: 積立投資が1つの系列にしか入らない人(分ける前の本人)はそのままでよい
- **利回りをやめたらカテゴリも持たない**: 使わない設定を items.json に残さない(既定に戻ったら消す、E07-14と同じ)
- 選べるカテゴリは、手元の明細に付いている積立投資のカテゴリ(Driveを読まずに済む)。
  選んでいたカテゴリが明細から消えても、選んだままだと分かるよう選択肢に残す

## 検証 (2026-09-27)
**JVMユニットテスト(346件、うち追加2件)**: `MetricFormTest`(カテゴリを利回りと一緒に持ち、利回りをやめれば
持たない)、`SettingsTest`(`investCategory` で書き、リマインダーの `fundId` はそのまま)、`CategoriesTest`
(カテゴリごとの月平均、明細の無いカテゴリはnull)

**エミュレータで、本人のデータで確認した**(額は出していない):
- 投資信託のローカルの行にだけ一時的に 利回り3%・カテゴリ「積立投資」を入れ(Driveには書かない)、詳細を%表示で開いた。
  「積立は明細のカテゴリ「積立投資」の月平均」と出た
- 3行の%を、DBの明細をカテゴリ「積立投資」だけで別に計算した値と比べ、3行とも一致。
  積立投資の全部(年金の掛金を含む)で計算した値とは違うことも見た(年金の掛金が入っていない)
- 変更画面に「全部 / 年金の掛金 / 積立投資」が出た(保存は押していない)
- 最後に一時的な値を消し、表示を「実額」に戻した

## 未検証・未実装のまま残したこと
- カテゴリを保存してDriveに書き、同期で戻ることは実機で見ていない(ユニットテストの読み戻しだけ)。
  利回りは本人がスマホ(2.9.0)で保存し、同期で戻ることを確かめた(E09-03)。2.9.0にはカテゴリの選択肢が無いので、
  2.10.0を入れて「積立投資」を選ぶまでは、投資信託の積立額に年金の掛金も入る
- 積立投資の目安(E10-04)の「今の積立」は、今までどおり積立投資の全部(年金の掛金を含む)。
  目安はNISAだけでなく「投資に回すお金」全体の話なので変えていない
- 1つの系列に2つ以上のカテゴリを選ぶことはできない
