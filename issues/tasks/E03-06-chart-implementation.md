# E03-06: グラフ実装(チャートライブラリ選定・配色)
親: [E03: ダッシュボードUI・詳細画面](../epics/E03-dashboard-ui.md)

## 概要
E03-02の時系列グラフを実際に描画する。Compose対応のチャートライブラリ
(Vico等)を選定し、ライト/ダークモード両方で見やすい配色ルールを
決める。

## 完了条件
Metric詳細画面で、実際の時系列データが折れ線/棒グラフで表示される。

## 作ったもの

| ファイル | 中身 |
|---------|------|
| `ui/chart/Charts.kt` | `LineChart`(推移の折れ線)、`ChangeBarChart`(増減の棒)、配色ルール |
| `ui/chart/ChartScale.kt` | 縦軸の範囲と目盛り(`ValueAxis`)。描画から切り離した純粋関数 |
| `ui/Formatters.kt` | 目盛り用の短い金額表記 `yenCompact`(`552万` `1.2億`) |

Metricの詳細画面に、月次の表の上へ2つ出す:
1. **推移の折れ線**: 系列の全点。最新の点を大きく描く
2. **月ごとの増減の棒**: 0を基準に上下。データの無い月は棒を描かない

## 設計の決定

### ライブラリは使わず、Canvasで描いた
Vico(当時3.3.1)を候補にしたが、Composeの `Canvas` で自前で描いた。

- 要るのは折れ線と増減の棒だけ(後で積み上げ。E07-13)。数百行で足りる
- **E06-04のプライバシーモード**(金額を隠して形だけ見せる)で、目盛りの
  文字だけ消す・%表記に替える、といった細かい制御が要る。自前なら
  `yenCompact` を差し替えるだけで済む
- Vicoはメジャー版ごとにAPIが大きく変わってきた。このプロジェクトは
  AGP 9 / Kotlin 2.4 と新しく、相性の確認にも手間がかかる

グラフの要求が増えて(拡大・スクロール・タップで値を出す、など)自前が
重くなったら、そのときライブラリに乗り換える。描く側は `LineChart` /
`ChangeBarChart` の2つに閉じているので、差し替えは画面側に響かない。

### 配色ルール
色は全部MaterialThemeから取り、グラフ側でライト/ダークを分岐しない。

| 役割 | 色 |
|------|----|
| 系列の線・増えた棒 | `primary` |
| 減った棒 | `error`(E03-03の増減の文字色と揃える) |
| 目盛りの線 | `outlineVariant`(データより目立たせない) |
| 0の基準線 | `outline` |
| 目盛りの文字 | `onSurfaceVariant` |

複数系列を1枚に描くとき(E07-13)は、このルールに系列ごとの色を足す。

### 横軸は日付の実際の間隔で置く
資産推移CSVの点は等間隔ではない(実データでは直近1か月に点が詰まっている)。
点の順番で並べると形が歪むので、日付(epoch日)に比例した位置に置く。

### 縦軸は切りのいい値で区切る
目盛りは 1・2・5 × 10のべき の間隔。データの最小〜最大ぴったりに置くと
`5,432,108` のような読めない値になる。表記は `552万` のように短くする。

### 月の増減の棒は、0を必ず入れる
増えた月しか無くても0の基準線を描く。上下の向きで増減を読ませるため。

## 検証 (2026-09-25)

**JVMユニットテスト(129件、うち追加7件)**: `ValueAxisTest`
- 目盛りが切りのいい間隔でデータを包む、増減の棒は0を含む
- 全部同じ値でも範囲がつぶれない、データなしでも落ちない
- 短い金額表記

**エミュレータで実データ**: 「合計」の詳細画面をライトとダークの両方で
スクリーンショットを撮って確認した(実額が写るので確認後に削除)。
- 折れ線は1年ぶん37点、直近1か月に点が詰まっている様子がそのまま出た
- 増減の棒は、減った月が赤で0より下に出た
- ダークでも線・棒・目盛りが読める(テーマの色がそのまま切り替わる)
- **最新の点(大きい丸)が右端で少し切れていた**。右の余白(4dp)が点の
  半径(4.5dp)より小さかったため。6dpにして、切れないことを確認した

テストの値について: `ValueAxisTest` の最初の版で、スクリーンショットで見た
実額に近い値をそのまま使っていた。コミット前に気づいて架空の値に替えた
(公開リポジトリに実額を入れない)。

## 未検証・未実装のまま残したこと
