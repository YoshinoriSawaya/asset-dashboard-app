# 資産ダッシュボード

個人用の資産形成ダッシュボードAndroidアプリ。銀行から落としたCSVを
Google Driveの `inbox` に放り込むだけで取り込み、資産の推移を1か所で見る。
ホームウィジェットは「何か対応が必要か」だけを色で知らせる。

ストア非公開・自分専用。マネーフォワード等への課金を避けるために自作している。

## いまどこまで動くか

**v2。2026-09-26からスマホに入れて使っている。** 今の版と版ごとの変化は [CHANGELOG.md](CHANGELOG.md)。
アプリを開いて「Driveと同期」を押すと:

1. Googleアカウントで認可(初回だけ同意画面)
2. `/資産アプリ/` 配下の6フォルダを用意(無ければ作る)
3. `inbox` のCSVを読んでパース(銀行の明細、資産推移、カードの利用明細、証券口座の保有商品一覧)
4. 正規化した結果を `backup` にJSONで保存
5. 元ファイルを `processed` へ移動
6. 問題があれば `logs` に理由を残す
7. `backup`・`corrections`・`settings` からローカルDBを作り直す

ボタンを押さなくても、開いたときに手元のデータが30日より古ければ
自動で同じことをする。

トップ画面に項目(目標と系列)が最新値と今月の増減付きで並び、
タップすると詳細画面(推移の折れ線・増減の棒・月ごとの表、Goalの進捗など)に移る。
系列は色分けされ、一覧の色の丸・推移の線・純資産の円グラフで同じ色になる。
リマインダーはトップでは「リマインダー(全N件)」の1行にまとめ、タップで期日順の一覧を開く。
銀行明細の残高から口座ごとの残高の系列もでき、系列には「まとめ先」を選べる(NISAの区分を投資信託の内訳に、など)。
トップから月次・年次サマリー(系列ごとの増減と入出金)も開ける。
詳細画面から値の補正・手入力もでき、Driveの corrections に保存される。
トップには前回の同期の要約が出て、タップで詳細(読めなかった行など)を見られる。
資産の状況をAI相談用のMarkdownにしてコピーすることもできる。
目標(Goal)を追加・編集でき、進捗が一覧と詳細に出る。目標額は「生活費の何か月分」で自動にもできる(振替などは摘要の言葉で除く)。
ふるさと納税のような「毎年1月にリセットする枠」も目標にでき、使った分を足していける。
期日のある目標には「期日の何か月前から積み増すか」を決められ、その時期に入ると通知が届き、期日まで月々いくら要るかが出る。
目標に「足りないとき何か月で埋めるか」を決めると、満たしているかと月々の積立額が1行で出る。
明細には摘要の言葉でカテゴリ(生活費・遊び代・大型出費・振替・積立投資)を付けられ、収入から消費と守りのお金を
引いた残りの8割を「積立投資の目安」として、今の積立額と比べて出す。
生活防衛資金には下限を決められ、期日の目標が足りないときに下限までなら取り崩して補えるかが出る(下限を割ると強めに知らせる)。
同じ口座(系列)を複数の目標で測るときは、一覧の上の目標から順に残高を割り当て、系列の推移を目標ごとに色分けした積み上げグラフで見られる。
系列の表示名の変更や、一覧から隠すこともできる
(どちらもDriveの settings に保存)。
系列ごとに「純資産に数える」を選ぶと、トップのいちばん上に純資産(選んだ系列の合計)が出て、
タップで推移と、系列ごとの配分(円グラフ)を見られる(「合計」とその内訳のように重なる系列があるので、全部は足さない)。
ボーナスなどの額を入れると、下限の回復→積み増し中の今月分→各目標の不足分(一覧の順)の順で、
どの目標にいくら回すかの案が出る(案だけで、何も保存しない)。

ホーム画面には、同期が必要になると赤くなるウィジェットを置ける(金額は出さない)。
目標の詳細には、今のペースならいつ届くかの目安も出る。生活防衛資金には
「生活費の何か月分あるか」「このペースだといつ目標を割るか」も出る。
向こう3年の大型出費の予定(見込み額つきのリマインダーと期日のある目標)も一覧できる。
家電や車のように何年かごとに来る出費は、リマインダーに「何年ごと」と積立先を入れると、積立の目標に
向こう1年に要る額と、ならした月々の積立額が出る(物価上昇率も掛けられる)。
予定が多ければ、1行1項目のCSVをDriveの `settings/plan.csv` に置いて、まとめて取り込める。
アプリは開くときに生体認証か端末の画面ロックで守る。人前では金額を「%」や「マスク」に切り替えられる。入れ直しても同期すれば元に戻る。
通知は端末が1日1回自分で確かめて出す(同期の催促、リマインダー、目標の不足、年末の枠、積み増しの時期、生活防衛資金の下限)。
サーバーやFCMは使わない。

進捗と設計の経緯は [issues/README.md](issues/README.md) を見る。

## Driveのフォルダ構成

```
マイドライブ/資産アプリ/
  inbox/        ← CSVをここに放り込む(人間が触るのはここだけ)
  processed/    ← 取り込み済みCSVの移動先
  backup/       ← 正規化済みデータ(JSON)
  corrections/  ← 手動補正
  settings/     ← 項目(Goal・Reminderなど)の定義、明細のカテゴリ(categories.json)、取り込む予定(plan.csv)
  logs/         ← 取り込み失敗の記録
```

## ビルドと実行

このマシンでは `java` も `adb` もPATHに入っていないため、
`./gradlew` をそのまま叩いても動かない。

**手順は [docs/development.md](docs/development.md) にまとめてある。**
ビルド、エミュレータの起動、画面の確認、ログの見方、DBの覗き方まで。

## 構成

| 場所 | 中身 |
|------|------|
| `app/src/main/java/.../drive/` | Drive API、認可、同期の流れ |
| `app/src/main/java/.../csv/` | CSVのパース、バリデーション、重複検出 |
| `app/src/main/java/.../data/` | Room(ローカルキャッシュ)と、表示用の計算(集計・目標・予測・純資産) |
| `app/src/main/java/.../ui/` | Composeの画面と、グラフ(`ui/chart/`) |
| `app/src/main/java/.../notify/` | 端末の中で出す通知(1日1回の確認) |
| `app/src/main/java/.../widget/` | ホーム画面のウィジェット(Glance) |
| `app/src/main/java/.../lock/` | アプリのロック(生体認証・画面ロック) |
| `issues/` | エピックとタスク。設計の経緯もここ |
| `docs/` | 全体の仕組みと開発手順 |

設計の考え方は [docs/architecture.md](docs/architecture.md)。

## 個人情報の扱い

このリポジトリに**実データのCSVは置かない**。口座番号・氏名・残高が入る。
テストは実ファイルで起きた事象を最小の形に写したものを使っている。

`.gitignore` で keystore・`google-services.json`・`local.properties` も
除外してある。
