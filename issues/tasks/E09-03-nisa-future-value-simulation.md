# E09-03: NISA資産の将来価値シミュレーション
親: [E09: 将来予測機能](../epics/E09-forecasting.md)

## 概要
現在の月次積立額(◯円)を継続した場合の将来評価額を、
簡易的な複利計算(想定利回りは自分で設定可能)でシミュレーションする。
あくまで目安であり、投資判断の保証ではないことを明示する。

## 完了条件
「このペースで積立を続けた場合、N年後に約◯万円」という目安が
NISA Metric詳細画面に表示される。想定利回りは自分で調整できる。

## 作ったもの
- `data/FutureValue.kt`(純粋関数):
  ```
  評価額 = 今の評価額 × (1 + m)^n + 月の積立額 × ((1 + m)^n − 1) / m
    m = (1 + 年利回り)^(1/12) − 1、n = 月数
  ```
  10・20・30年後の評価額と、積み立てた元本(今の評価額 + 積立額の合計)を出す
- Metricの「名前・表示を変更」に**想定利回り(年%)**の欄。入れた系列だけ、詳細の「名前・表示を変更」の下に
  「このまま積み立てると(年3%)」と3行を出す。%表示のときは金額を伏せ、元本に対する増え方(+◯%)だけが見える
- 積立額は `InvestPlan.currentMonthlyYen`(積立投資の目安(E10-04)の「今の積立額」と同じ値)。
  平均に使う月の選び方を `InvestPlan` の中で共有した

## 設計の決定(本人が決めたもの、2026-09-26)
- **積立額は明細の「積立投資」の月平均**(E07-21のカテゴリ)。入力を増やさず、積立投資の目安と同じ数字になる。
  系列ごとに手で入れる案・両方持つ案は選ばなかった
- **10・20・30年後の3行に固定**。年数の入力を増やさない

## 設計の決定(こちらで決めたもの)
- **NISAの系列をコードで決めない**: `投資信託`→NISAの対応付けを持たない方針(CLAUDE.md)どおり、
  人が利回りを入れた系列を「投資の系列」とみなす。利回りが空の系列には出さない
- **列を増やさない**: 利回りはDBでは既存の `growthRateBp` 列(Goalでは物価上昇率)に入れる。
  Reminderの見込み額が `targetYen` を使うのと同じ(汎用スキーマ)。Roomのマイグレーションが要らない。
  `items.json` では意味が違うので `expectedReturnBp` という別の名前で書く
- **月ごとの複利、月の利回りは年利回りから逆算**: 年利回り÷12だと、1年の増え方が想定より少し大きくなる
- **積立は月末に入れる扱い**、**1万円単位で四捨五入**: 目安を多めに出さない・細かい桁に意味が無い
- **利回りの上限は20%**: 桁の打ち間違いで途方もない額を出さない(物価上昇率(E07-15)と同じ)
- **積立額が分からないときも出す**: 積立投資の明細が無ければ「今の評価額だけを運用した場合」と断って出す
- 「投資の判断を保証するものではない」と画面に書いた(概要の要求)

## 検証 (2026-09-26)
**JVMユニットテスト(343件、うち追加8件)**: `FutureValueTest`(利回り0、積立なしで年利回りどおり増える、
1か月ずつ積み上げた値との一致、出さないとき、詳細に出す系列)、`MetricFormTest`(利回りの入力・空でやめる・範囲外)、
`SettingsTest`(利回りの読み戻し、古い設定)、`CategoriesTest`(積立投資の月平均)

**エミュレータで、本人のデータで確認した**(額は出していない):
- ローカルDBの `投資信託` の行にだけ一時的に3%を入れ(Driveには書かない)、詳細を%表示で開いた。
  3行が出て、金額は伏せられ、元本に対する増え方だけが出た
- 画面の3行の%を、DBの最新の点と明細(積立投資の種類、直近6か月)から別に計算した値と比べ、3行とも一致した。
  積立投資のカテゴリはすでに付いていて、積立額は明細から取れていた
- 「名前・表示を変更」の欄に今の利回りが入っていることを見た(保存はDriveに書くので押していない)
- 最後に一時的な利回りを消し、表示を「実額」に戻した

## 未検証・未実装のまま残したこと
- **利回りを保存してDriveのitems.jsonに書き、同期し直して戻ることは実機で見ていない**(ユニットテストの読み戻しだけ)
- 積立額は明細全体の積立投資の平均なので、**利回りを入れた系列が2つあると、両方に同じ積立額を足す**
  (NISAの系列を1つにまとめて(E07-18)、その親に入れる使い方を想定)
- NISAの年間・生涯の投資枠(上限)で積立が止まることは見込まない
- 取り崩し・税金・手数料・物価上昇は見込まない
- AI用の書き出し(E03-07)には入れていない
