# E07-14: Metric項目の表示名・非表示
親: [E07: 目標(Goal)管理機能](../epics/E07-goal-management.md)

## 概要
資産推移CSVの列から自動で生えたMetric項目(E02-01)の、表示名を変えたり、
一覧から隠したりできるようにする。例: `投資信託` を `NISA` と呼ぶ、
`合計` を隠す。

CLAUDE.mdで「表示名や目標との紐付けはE07の仕事」としていた部分。
metricKey(CSVの列名)は変えず、表示だけを変える。

## 完了条件
Metric項目の名前を変える・隠す・元に戻すができ、Driveの settings に保存される。
隠した項目も、どこかから見つけて戻せる。

## 作ったもの
| 入口 | できること |
|------|-----------|
| Metricの詳細の「名前・表示を変更」 | 表示名を変える、一覧から隠す、元に戻す |
| トップの「隠している項目(N)」 | 隠した項目の一覧。タップで同じ画面を開き、隠すのをやめられる |

`MetricEditScreen` と、変更の組み立て `MetricForm`(純粋関数)。
保存は目標(E07-01)と同じ `editOnDrive` を通り、Driveの `settings/items.json` に書く。

## 設計の決定

### 列名(metricKey)は変えない
変えるのは表示だけ。CSVの列名はそのまま系列の鍵で、補正(corrections)も
目標の紐づけもこれを指している。`投資信託`→NISAのような対応付けを
コードに持たない(CLAUDE.md)方針とも合う。人が画面で名前を付ける。

### 既定に戻ったら、settingsから消す
settingsには「人が変えたもの」だけを書く(E02-01)。名前を列名に戻し、
隠すのもやめたら、書いておく理由が無いので消す。次の作り直しで自動の項目に
戻り、items.jsonも膨らまない。「元に戻す」ボタンも同じ動き。

### 隠した項目は、トップから必ず戻せる
隠すと一覧から消えるので、戻す入口が無いと二度と触れない。隠している
項目があるときだけ、トップの下に「隠している項目(N)」を出す。

### 隠すとサマリーと書き出しからも外れる
月次・年次サマリー(E03-03)とAI用の書き出し(E03-07)は、隠していない
項目だけを使う。`合計` のように他の列と重なる系列を隠せば、書き出しで
二重に数えられることも減る。画面にもそう書いた。

(名前の変更・隠す・既定に戻したら消す・空の名前・既定かどうか)

**エミュレータで、Driveに実際に書いて確認した**(最後に全部元に戻した):

| 手順 | 結果 |
|------|------|
| `投資信託` を `NISA-test` に変える | 一覧の名前が変わった |
| ローカルの項目を全部消して同期 | 名前と「隠す」がDriveから戻った |
| 「隠している項目」から戻す | 一覧に戻った |
| `合計` を隠す | 一覧から消え、「隠している項目(1)」に出た |
| 隠すのをやめる / 「元に戻す」 | 既定に戻った |
| ローカルを消して同期し直す | 4項目とも既定(settingsに何も残っていない) |

途中、確認の手順が保存の完了(8〜10秒)を待たずに次へ進み、別の項目を
隠してしまった。手順を「保存中...が消えるまで待つ」に直してやり直した。
アプリの不具合ではない。
