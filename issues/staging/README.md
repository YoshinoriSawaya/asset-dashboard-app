# staging: エピック・タスクの下書き置き場

チャットでまとめて作ったエピックやタスクの下書きを、番号や配置を気にせず
フォルダ単位で置く場所(例: `20260928-something/README.md`)。

Claudeがこのリポジトリで作業を始めるときに見つけて、次の順で分配する。

1. 各下書きが新規エピックか、既存エピック配下の新規タスクかを判断する
2. 番号を振る(新規エピックは次の空いているE番号、タスクは親エピック配下の次の番号)
3. 命名規則(`EXX-slug.md` / `EXX-NN-slug.md`)と体裁(親子の相互リンク、概要、完了条件、ステータス)に整えて
   `epics/`・`tasks/` へ移す
4. 親エピックのチェックボックス一覧を更新し、新規エピックなら `issues/README.md` のエピック表にも行を足す
5. 配分し終えたら、そのバッチのフォルダを削除する(経緯はgitの履歴に残る)

下書きの内容を鵜呑みにしない。やる価値があるか・依存関係が正しいか・前の決定とぶつからないかは、
分配のときに本人と確認する。

このREADME.mdは消さない。
